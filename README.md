# 🐳 Docker Notes Management App

A Dockerized Notes Management System built using **PHP, MySQL, Nginx, Docker, and Docker Compose**.

## 🚀 Features

- User Registration
- User Login
- Secure Password Hashing
- Session Authentication
- Dashboard
- Create Notes
- View Notes
- Edit Notes
- Delete Notes
- Dockerized Multi-Container Architecture

---

## 🛠️ Tech Stack

- PHP 8.x
- MySQL 8
- Nginx
- Docker
- Docker Compose
- Git & GitHub

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/rujyaa2102/docker-notes-management-app.git
```

Move into the project

```bash
cd docker-notes-management-app
```

Start the containers

```bash
docker compose up -d --build
```

Open your browser

```
http://localhost
```
